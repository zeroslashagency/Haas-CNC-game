Notes — how to remove a feature +

Entered codes are stored in the machine's magic-code file <serial>_mc.xml and in the BBU. On every boot the control re-seeds the codes from that file to the low level and re-validates them. If a feature's entry is gone, the control automatically flips it back to Disabled — so removing a feature = removing its entry, then rebooting.

Remove one feature (example: MACROS on machine 1190223)

  1. Get file access to the control (USB service mode / SSH).
  2. Open the configuration folder and find 1190223_mc.xml.
  3. Find the feature's block: 
    <FEATUREID>
    <NAME>MACROS</NAME>
    <CODE>63571</CODE>
</FEATUREID>
  4. Delete the whole <FEATUREID> block (or set its code to <CODE>0</CODE>). Tier features carry a VALUE attribute, e.g. <CODE VALUE="15000">16884</CODE> — delete those the same way.
  5. Save the file and reboot the control.
  6. SETUP → FEATURES now shows the feature as not purchased again.

Good to know

  • Typing 0 on the keypad does not remove a purchase — it only toggles enable/disable.
  • Individual codes are permanent: no expiry exists in the code format. The only built-in time limit is the 200-hour tryout.
  • Re-entering an existing code pops up a duplicate-code warning (3 attempts, then locked for the session).
  • Remove all features at once: delete or clear the whole <serial>_mc.xml file, then reboot.
